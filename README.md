# Amazon Marketplace Product Intelligence Platform

AI Engineer Training Project

## Description

An AI-powered product intelligence platform that collects Amazon
product and review data, performs analytical processing, and provides
four analytical features through a Streamlit application.

## Planned Features

1. Similar Product Recommendation
2. Review Sentiment Analysis
3. Thumbnail-based Visual Grouping
4. Price Tier Classification

## Tech Stack

- Python
- Git
- GitHub
- pandas
- scikit-learn
- Streamlit
- Jupyter Notebooks
